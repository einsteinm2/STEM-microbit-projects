## Digital vs Analog Signals on Micro:bit (Real-Time Serial Plotter Demo)

Learn how to visualize **digital** and **analog** signals in real time using the BBC micro:bit.
In this project, we use:
- **Touch pin P0** (digital input)
- **Potentiometer on P1** (analog input)
- **Built-in light sensor** (analog reading)

This activity is perfect for beginners, makers, and STEM classrooms exploring how different sensor values change over time in the serial plotter.

---

### Materials
- BBC Micro:bit (v1 or v2)
- Potentiometer (connected to pin P1)
- Jumper wires
- USB cable and power source
- Computer with MakeCode serial plotter

---

### Code
The MakeCode program reads digital and analog values and sends them to the serial plotter in real time.

Code file: [`digital-vs-analog-signals.js`](./digital-vs-analog-signals.js)
